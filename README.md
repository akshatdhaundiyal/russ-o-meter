## ✨ Features

- 📱 **Mobile-First Experience**: 5-mode scrollable bottom dock, sticky top status bar with live audio toggle, and responsive desktop sidebar.
- 👑 **Lead VC Persona Carousel**: Pick from *Russ Hanneman* (*Tres Comas Capital*), *Gavin Belson* (*Hooli*), *Chad DePIN-DAO* (*Proof-of-Hype*), or *Garry Sequoia* (*YC*).
- 🎲 **"Surprise Me" Idea Randomizer**: 1-tap generator with 20+ hilarious mundane ideas.
- 🧪 **Valuation Multiplier Lab**: Interactive funding round slider + stackable buzzwords (*AI Agents +15x*, *Quantum +25x*, *Defense Tech +50x*) + anti-revenue penalties (*-85% for Paying Customers*).
- 🔥 **Burn Rate & Runway Simulator**: Runway countdown clock with real Silicon Valley expenses (*Idle H100s, Kombucha taps, Aspen sound baths*) + Emergency Panic buttons.
- 💎 **LP Dashboard & Cap Table**: Real-time fund valuation (AUM), interactive diluted cap table visualizer, and persistent saved pitch vault.
- 🥊 **2-Player Pitch Battle (Party Mode)**: Pass-and-play head-to-head battle with deliberation animations and VC judge roast verdicts.
- 📜 **Parody Legal Term Sheet**: Form NVCA-TRES-COMAS complete with clauses on vehicle door mechanics and tequila liquidation preferences.
- 🎨 **Canvas Social Share Card**: 1200x630 high-res card generator with 1-tap **Save PNG**, **Copy Image to Clipboard**, and native **Mobile Share API** support.
- 🔊 **Zero-Dependency Web Audio Synth**: Synthesizes real-time sound effects (*cha-chings*, rocket sweeps, celebration fanfare, and roasts) without external audio files.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) + [TanStack React Router](https://tanstack.com/router)
- **UI & Styling**: React 19, Tailwind CSS v4, Radix UI Primitives, Lucide Icons / Material Symbols
- **AI & Server**: Vercel AI SDK, OpenAI API / Lovable AI Gateway + Procedural Satire Engine Fallback
- **Sound**: Native Web Audio API
- **Build Tool**: Vite 8 + Nitro Server

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd russ-o-meter
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
